# Jakub Wojtas — portfolio

Personal portfolio site (English / Polish), built with React, Vite and Tailwind CSS.

## Development

```bash
npm install
npm run dev      # local dev server
npm run lint
npm run build    # production build in dist/
```

## Deployment

```bash
npm run deploy   # builds and publishes dist/ to the gh-pages branch
```

## Fonts

Typeset in FreeSans from [GNU FreeFont](https://www.gnu.org/software/freefont/) (GPL with font exception), subset to Latin and Latin Extended-A in `public/fonts/freesans/`.
